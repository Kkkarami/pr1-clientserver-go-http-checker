# pr1-go-http-health-checker

## Практична робота №1

**Тема:** Базові конструкції, структури даних та конкурентність у Go.

**Студент:** Феделеш Андрій КН-41

## Мета роботи

Ознайомитися з основами мови програмування Go, навчитися працювати зі структурами, методами та інтерфейсами, обробляти помилки, а також використовувати горутини для паралельного виконання завдань. Ознайомитися з механізмами синхронізації `sync.WaitGroup` та `sync.Mutex`.

## Використані технології

- **Go** — основна мова програмування.
- **net/http** — виконання HTTP-запитів.
- **fmt** — виведення результатів у консоль.
- **time** — вимірювання часу виконання запитів.
- **sync** — синхронізація горутин за допомогою `WaitGroup` та `Mutex`.

## Реалізація

### 1. Структура CheckResult

Створено структуру `CheckResult`, яка зберігає результати перевірки URL:

- `URL` — адреса вебсайту.
- `StatusCode` — HTTP-код відповіді.
- `Duration` — час виконання запиту.
- `Error` — інформація про помилку, якщо вона виникла.

### 2. Інтерфейс URLChecker

Створено інтерфейс `URLChecker` з методом `Check`, який приймає URL та повертає структуру `CheckResult`.

### 3. HTTPClient

Реалізовано структуру `HTTPClient`, яка містить HTTP-клієнт із тайм-аутом 5 секунд.

Метод `Check` виконує HTTP GET-запит, вимірює час його виконання, отримує статус відповіді та обробляє можливі помилки.

### 4. Перевірка URL (рівень 1)

Створено список із п'яти URL-адрес, серед яких чотири доступні вебсайти та одна неіснуюча адреса.

Перевірка виконується послідовно. Для кожної адреси виводяться URL, HTTP-статус, тривалість запиту та інформація про помилку.

### 5. Конкурентна перевірка URL (рівень 2)

Реалізовано паралельну перевірку URL за допомогою горутин.

Для синхронізації виконання використано:

- `sync.WaitGroup` — очікування завершення всіх горутин.
- `sync.Mutex` — захист спільної статистики від одночасного доступу.

Для збереження статистики створено структуру `Stats`, яка містить загальну кількість перевірок, кількість успішних відповідей зі статусом HTTP 200 та кількість помилок запитів.

Після завершення всіх перевірок програма виводить підсумкову статистику.

## Тестування

Для запуску програми використовується команда:

```powershell
go run .
```

Для перевірки програми на наявність гонок даних використовується:

```powershell
go run -race .
```

### Результати тестування

У результаті виконання програми отримано:

- Загальна кількість перевірок: 5.
- Успішні відповіді HTTP 200: 4.
- Помилки запитів: 1.

Помилка виникла під час перевірки неіснуючого домену, що підтверджує коректну обробку помилок мережевих запитів.

## Висновок

Під час виконання практичної роботи було освоєно основні конструкції мови Go, роботу зі структурами, методами та інтерфейсами. Реалізовано HTTP URL Health Checker для перевірки доступності вебсайтів.

Також було реалізовано конкурентне виконання перевірок за допомогою горутин, а для синхронізації використано `sync.WaitGroup` та `sync.Mutex`. Перевірка за допомогою Race Detector підтвердила відсутність виявлених гонок даних.

У результаті отримано практичні навички роботи з HTTP-запитами, обробкою помилок та конкурентністю в Go.
